## Featured Projects

### [Physics-Informed Neural Network — Pendulum Dynamics](https://github.com/Sarah4908/pendulum)

> A multilayer neural network built entirely from scratch using only NumPy, no deep learning frameworks.

- Implemented forward propagation, manual backpropagation, and gradient descent from first principles
- Derived backpropagation equations by hand using the chain rule across tanh-activated hidden layers
- Trained on simulated pendulum dynamics, reducing MSE loss from **1.28 → 0.024** over 5000 epochs
- Validated predicted angle and angular velocity trajectories against ground truth
